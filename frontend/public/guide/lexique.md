# Lexique

| Terme | Explication simple |
|---|---|
| **Action** | Une part d'une entreprise. Voir [La bourse en 10 minutes](bourse/la-bourse.md) |
| **Actionnaire** | Propriétaire d'actions d'une entreprise |
| **Aller-retour** | Acheter puis revendre : on paie deux fois des frais |
| **Analyse fondamentale** | Étude de l'entreprise : ventes, bénéfices, dettes, prix. Voir [Juger une entreprise](bourse/analyse-fondamentale.md) |
| **Analyse technique** | Étude du graphique du cours et des volumes. Voir [Lire un graphique](bourse/analyse-technique.md) |
| **BPA** | Bénéfice par action : le bénéfice net divisé par le nombre d'actions |
| **Capitalisation** | Valeur totale de l'entreprise en bourse : cours × nombre d'actions |
| **Capitaux propres** | Ce qui appartient aux actionnaires dans le bilan de l'entreprise |
| **Chandelier (bougie)** | Représentation d'une période sur un graphique : ouverture, plus haut, plus bas, clôture |
| **Chiffre d'affaires** | Total des ventes de l'entreprise sur l'année |
| **Clôture (cours de)** | Prix fixé en fin de séance, à 17 h 35 à Paris : le prix de référence de la journée |
| **Compte-titres ordinaire (CTO)** | Compte pour investir en bourse, sans avantage fiscal ni restriction de titres |
| **Cours** | Prix du dernier échange d'une action |
| **Croisement doré / de la mort** | Moyenne 50 jours qui passe au-dessus / en dessous de la moyenne 200 jours |
| **Dividende** | Part du bénéfice reversée aux actionnaires |
| **Diversification** | Répartir son argent sur plusieurs placements pour limiter le risque |
| **Éligible PEA** | Titre qui peut être détenu dans un PEA. Voir [Le PEA](bourse/pea.md) |
| **ETF (tracker)** | Fonds coté qui reproduit un indice. Voir [Les ETF](bourse/etf.md) |
| **Euronext** | L'entreprise qui gère les bourses de Paris, Amsterdam, Bruxelles, Milan, Lisbonne, Dublin et Oslo |
| **Fixing** | Moment où un prix unique est calculé pour équilibrer tous les ordres en attente (à l'ouverture et à la clôture) |
| **Fourchette** | Écart entre le meilleur prix d'achat proposé et le meilleur prix de vente |
| **Frais courants** | Frais annuels d'un ETF, prélevés directement dans sa valeur |
| **Indice** | Panier d'actions qui résume un marché : CAC 40, SBF 120, Euro Stoxx 50 |
| **ISIN** | Identifiant international unique d'un titre, par exemple `FR0000121014`. Les 2 premières lettres donnent le pays |
| **Liquidité** | Facilité à acheter ou vendre un titre sans faire bouger son prix |
| **MACD** | Indicateur de dynamique fondé sur deux moyennes mobiles (12 et 26 jours) |
| **Marge nette** | Bénéfice net ÷ chiffre d'affaires : ce que l'entreprise garde sur 100 € de ventes |
| **Moyenne mobile (MM50, MM200)** | Moyenne des 50 ou 200 derniers cours de clôture, recalculée chaque jour |
| **Ordre** | Instruction d'achat ou de vente donnée à sa banque. Voir [Passer un ordre](bourse/ordres-et-frais.md) |
| **Ordre à cours limité** | Ordre exécuté seulement à un prix maximum (achat) ou minimum (vente) choisi |
| **PEA** | Plan d'épargne en actions : compte avec un avantage fiscal après 5 ans. Voir [Le PEA](bourse/pea.md) |
| **PER** | Cours ÷ bénéfice par action : combien on paie pour 1 € de bénéfice annuel |
| **Plus-value latente** | Gain « sur le papier » sur des titres encore détenus |
| **Plus-value réalisée** | Gain réellement encaissé lors d'une vente |
| **Portefeuille** | L'ensemble de vos placements |
| **PRU** | Prix de revient unitaire : ce qu'a coûté en moyenne chaque titre, frais compris. Voir [Portefeuille](app/portefeuille.md) |
| **Rendement (du dividende)** | Dividende annuel ÷ cours, en % |
| **Réplication synthétique** | Technique qui permet à un ETF éligible au PEA de suivre un indice non européen |
| **RSI** | Indicateur de 0 à 100 : au-dessus de 70, l'action a beaucoup monté très vite ; sous 30, beaucoup baissé |
| **Score** | La note sur 100 de Cotalyx. Voir [Comprendre le score](app/score.md) |
| **Séance** | Une journée de bourse (9 h – 17 h 35 à Paris, en semaine) |
| **Support / résistance** | Niveau de prix où le cours a souvent rebondi / calé |
| **Ticker** | Code court d'un titre en bourse, par exemple `MC` pour LVMH (`MC.PA` chez Yahoo) |
| **Volatilité** | Ampleur des variations du cours : plus elle est forte, plus c'est risqué |
| **Volume** | Nombre d'actions échangées sur une période |
